# Architecture

This project is organized into a FastAPI backend, a React frontend, and supporting Docker and documentation assets.

## Backend

- API layer hosts REST endpoints.
- Analyzer modules cover static, Git, runtime, and test evidence.
- AI modules prepare graph reasoning, prompts, and LLM integration.
- Retrieval and simulation components support evidence gathering and safe validation.

## Frontend

- React app consumes backend APIs for analysis workflows and recommendations.
- Components, hooks, and services live under the frontend src tree.
